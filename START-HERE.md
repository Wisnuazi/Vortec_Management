# START HERE

## 1. Rename the project folder
Rename `Claude-Code-Project-Template` to your real project name.

## 2. Fill in these files first
1. `docs/PROJECT_CONTEXT.md`
2. `docs/REQUIREMENTS.md`
3. `docs/ARCHITECTURE.md`
4. `docs/DECISIONS.md`
5. `tasks/CURRENT_TASK.md`

## 3. Initialize Git

```bash
git init
git add .
git commit -m "chore: initialize project framework"
```

## 4. Start Claude Code

From the project root:

```bash
claude
```

Then use:

```text
Read CLAUDE.md and all required project context.

Understand the current architecture and project state.

Do not modify anything yet.

Report:
1. project purpose
2. architecture
3. current task
4. important technical decisions
5. risks or inconsistencies you found
```

## 5. Continue work

```text
Continue tasks/CURRENT_TASK.md.

Inspect the relevant implementation first.

Plan, implement, test, verify, and update documentation according to CLAUDE.md.
```

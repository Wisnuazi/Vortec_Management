# ASSESSMENT TEMPLATES

This folder contains reusable assessment templates for Claude Code and human review.

Templates:

1. `ASSESSMENT-DEVELOPMENT-PROGRAM-SYSTEM.md`
   - For software, platform, application, automation, integration, or system development assessment.

2. `ASSESSMENT-BUSINESS-ANALYSIS-MARKETING-PLAN.md`
   - For business opportunity, market, customer, positioning, competitor, pricing, and marketing plan assessment.

3. `ASSESSMENT-CONTENT-GTM-PLAN.md`
   - For content strategy and go-to-market execution assessment.

## General Usage

Claude should:
1. Read the project context first.
2. Fill the assessment using evidence.
3. Mark unknown items explicitly.
4. Never invent missing facts.
5. Separate OBSERVED, INFERRED, and ASSUMED findings.
6. Score only when sufficient evidence exists.
7. Finish with prioritized actions and a decision recommendation.

Recommended statuses:
- NOT STARTED
- IN REVIEW
- PARTIALLY READY
- READY
- BLOCKED
- REJECTED
